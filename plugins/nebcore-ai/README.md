# nebcore-ai

NebCore AI tools for Claude Code over MCP: issues, Kubernetes, GitOps, cost,
policy, and compliance, each call scoped to your account's permissions.

Requires `nebcli` on your PATH and a one-time `nebcli login`; Claude Code then
launches `nebcli mcp` on demand and your credential never leaves your machine.

Install, sign-in, and the full tool reference: <https://docs.nebcore.ai/nebcli>
